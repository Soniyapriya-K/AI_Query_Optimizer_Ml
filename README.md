# AI-Powered Database Query Optimizer

An AI + Machine Learning system that analyzes SQL queries,
detects bottlenecks, predicts performance,
and recommends optimizations.

## Features
- SQL query analysis
- ML performance prediction
- Query optimization
- Index recommendation
- Flask web app

## Tech Stack
- Python
- Flask
- Scikit-learn
- SQLParse
